# LocalGateway Go SDK

LocalGateway 管理面的薄 Go 客户端。模块路径为
`github.com/HuanyuMark/localgateway-go`，当前版本 **v0.2.0**。

provider 生命周期库（监听、内建端点、OpenAPI 组装、注册重试与优雅退出）位于
独立仓库 `github.com/HuanyuMark/localgateway-go-provider`。本仓库只包含 client
与 OpenAPI 生成物，不包含 provider、示例或 Rust workspace。

```text
localgateway-go/
├─ generated/gatewayapi/ # openapi-generator 生成物，禁止手改
├─ client/               # 手写胶水层：端口读取、握手、注册/PATCH/注销
├─ generate.ps1          # 可复现的生成脚本
└─ go.mod                # module github.com/HuanyuMark/localgateway-go
```

| 目录 | 是否手写 | 说明 |
|---|---|---|
| `generated/gatewayapi` | 否 | 管理面 OpenAPI 生成的模型与 HTTP 客户端，仅由 `generate.ps1` 更新；属于 `github.com/HuanyuMark/localgateway-go` 模块 |
| `client` | 是 | package `localgateway`：端口读取、session 握手、注册/PATCH/注销、401 与换端口重试 |

## 安装

```powershell
go get github.com/HuanyuMark/localgateway-go@v0.2.0
```

```go
import (
    localgateway "github.com/HuanyuMark/localgateway-go/client"
    "github.com/HuanyuMark/localgateway-go/generated/gatewayapi"
)
```

`generated/gatewayapi` 是管理面请求/响应模型所在的包，client 内部会使用它；
需要直接构造注册请求或读取响应时也可以导入。

需要 provider 库时改用独立模块：

```powershell
go get github.com/HuanyuMark/localgateway-go-provider@v0.2.0
```

## 通过网关模块代理引入

外部项目可以通过网关内置的 Go 模块代理获取 SDK：

```powershell
$env:GOPROXY = "http://127.0.0.1:47821/gw/goproxy,https://goproxy.cn,direct"
$env:GONOSUMDB = "github.com/HuanyuMark/*"   # 本地代理无法访问公共校验和数据库时使用
```

```powershell
go get github.com/HuanyuMark/localgateway-go@v0.2.0
go mod tidy
go build
```

逗号列表让网关返回 404 时回退到公共代理（示例用 `goproxy.cn`，按网络环境替换为
`proxy.golang.org` 等），同一项目里的其它公开模块不受影响。`GOSUMDB=off` 会关闭
所有模块的校验，仅在离线或排障时使用。按服务生成的调用端客户端由网关单独分发，
其模块路径与 `go get` 用法以网关文档为准；本仓库的 client 使用上面的 GitHub 路径。

## 重新生成 `generated/gatewayapi`

生成物已提交入库，`go build` / `go test` 不依赖 Java、OpenAPI Generator jar 或
`.cache` 目录。只有管理面契约变化时才需要重新生成。

### 独立仓库

本仓库没有 Rust workspace，需显式传入生成器 jar 与 OpenAPI 文档：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File generate.ps1 `
  -Jar C:\tools\openapi-generator-cli.jar `
  -Spec C:\path\to\openapi.json
```

未传 `-Jar` / `-Spec` 时脚本会按仓库根推导默认位置；文件不存在时直接报错并提示
传入对应参数。默认输出仍是 `generated/gatewayapi`。

### LocalGateway monorepo

在 monorepo 的 `sdk/go/` 下运行时，脚本会自动识别两层以上的 `crates/gateway-admin`，
把 monorepo 根作为默认路径基准：

```powershell
# 从仓库根目录导出当前契约，然后重新生成
cargo run -q -p gateway-admin --example dump-openapi -- target/openapi.json
powershell -NoProfile -ExecutionPolicy Bypass -File sdk/go/generate.ps1
```

`generate.ps1` 参数（未指定时按仓库相对路径推导）：

| 参数 | 默认值 |
|---|---|
| `-Jar` | `<repo>/.cache/openapi-generator/7.26.0/openapi-generator-cli.jar` |
| `-Spec` | `<repo>/target/openapi.json` |
| `-Output` | `generated/gatewayapi`（相对脚本所在目录） |
| `-Java` | `$JAVA_HOME/bin/java.exe`（存在时），否则 PATH 中的 `java` |
| `-JavaHome` | 指定 JDK 根目录，推导 `bin/java.exe` |
| `-PackageName` | `gatewayapi` |
| `-ExportSpec` | 先在 monorepo 中执行 `cargo ... dump-openapi`（独立仓库不支持） |

生成器版本记录在 `generated/gatewayapi/.openapi-generator/VERSION`（当前 **7.26.0**）。
生成文件头带有 `Code generated by OpenAPI Generator ... DO NOT EDIT.`，不要手工修改。
脚本会清空输出目录后重新生成，并删除 `.travis.yml`、`git_push.sh`、`.gitignore`
等与本仓库无关的样板文件。生成参数固定为
`packageName=gatewayapi,isGoSubmodule=true,withGoMod=false`。

## client 薄运行时

```go
import (
    "context"
    "time"

    localgateway "github.com/HuanyuMark/localgateway-go/client"
)

client, err := localgateway.New(localgateway.Options{}) // 读取注册表端口
// 或显式指定：localgateway.New(localgateway.Options{BaseURL: "http://127.0.0.1:47821"})

ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()

registration, err := client.Register(ctx, "my-service", localgateway.RegisterOptions{
    Port:    8080,
    Version: "1.0.0",
    Probe:   localgateway.Probe{Path: "/health"},
})
```

端口发现默认读取 `HKCU\Software\LocalGateway\port`。可用环境变量
`LOCALGATEWAY_CONFIG_REGISTRY` 把子键重定向到测试或自定义作用域，规则与网关一致：
接受 `HKCU:\Software\...`、`HKCU\Software\...`、`HKEY_CURRENT_USER\Software\...`
与裸子键 `Software\...`；首尾空白忽略，空值视为未设置。`ReadPort` 的错误信息会
带上实际使用的子键，`errors.Is(err, ErrPortNotConfigured)` 仍可判定“未配置”。

- `Register` 对应 `PUT /gw/services/{name}`；`Port`、`Version`、`Probe.Path` 必填，
  缺失时在发请求前返回 `ErrInvalidPort` / `ErrInvalidVersion` / `ErrInvalidProbe`。
- 可选字段：`APIInfo`、`ProjectRoot`、`NotifyURL`；空值不会写入请求体。
- 首次写操作会懒执行 `POST /gw/session` 并缓存 token。
- 任意写请求收到 `401` 时会静默重新握手并**只重试一次**。
- 注册 / PATCH / DELETE 遇到连接失败（网关重启或换端口）时，会重新读取
  `PortReader`、刷新基地址并重试一次；未配置 `PortReader` 时保持直接失败。
- `SetBaseURL(url)` 手动切换管理面地址并丢弃旧 token；`RefreshBaseURL()` 重新读取
  `PortReader`（未配置时返回 `ErrNoPortReader`）。
- `Patch` 只发送设置过的字段；`Delete(ctx, name)` 注销。
- 测试注入点：`Options.PortReader func() (uint16, error)` 与 `Options.HTTPClient`。

## 测试

```powershell
gofmt -l .      # 应无输出
go vet ./...
go test ./...
go build ./...
```

- `client/client_test.go`：握手字段、401 恰好一次重试、PATCH、校验失败不发请求、
  注入端口读取、换地址与连接失败刷新、端口解析。
- `generate.ps1` 的生成结果与已提交的 `generated/gatewayapi` 一致时，重新生成后
  `git status` 应保持干净。

## 限制

- 端口读取走 `golang.org/x/sys/windows/registry`，默认键为
  `HKCU\Software\LocalGateway`，可用 `LOCALGATEWAY_CONFIG_REGISTRY` 重定向；仅
  Windows 可用。其它平台 `ReadPort` 返回 `ErrPortUnsupported`，请注入
  `Options.PortReader`。
- 契约首版只支持 `http` 协议；`Protocol` 固定发送 `http`。
- token 不主动续期，依赖 401 后的重新握手。
- PATCH 无法清空 `apiInfo` / `projectRoot`（契约首版不支持 `null` 清空）。
- 生成的枚举比较严格：网关返回未知枚举值时解码会失败。
- 重启预通知只刷新基地址，不自动重新注册；网关重启后可用 `RefreshBaseURL` 兜底。
- 需要注册重试、内建探活端点或 OpenAPI 自动组装时，请使用
  `github.com/HuanyuMark/localgateway-go-provider`。
